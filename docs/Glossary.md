# Password Generator Glossary

## 🔐 Password

A string of characters used to authenticate a user or access a system. Passwords are typically generated by the Password Generator application based on the selected character classes and length.

## 🔄 Character Class

A set of characters that can be included in a generated password. The Password Generator supports the following character classes:
- Digits (0-9)
- Lowercase letters (a-z)
- Uppercase letters (A-Z)
- Symbols (?-*%!@#_$.:;/)
- Extra symbols (€¢£¥₦§®©™∑∆µπ)
- Brackets ([]{}()<>)
- Others (,|\'"+=`~^& )

## 🔄 Length

The number of characters in a generated password. The user can specify the desired length of the password using the length input field in the Password Generator application.

## 🔄 Clipboard

A temporary storage area in the operating system where data can be copied and pasted. The Password Generator provides a copy action to copy the generated password to the system clipboard.

## 🔄 HTML

Hypertext Markup Language, the standard markup language for creating web pages and web applications. The Password Generator is built using HTML to define the structure and content of the application.

## 🔄 CSS

Cascading Style Sheets, a style sheet language used for describing the presentation of a document written in HTML. The Password Generator uses CSS to style the user interface and layout of the application.

## 🔄 JavaScript

A programming language that enables interactive web pages and web applications. The Password Generator uses JavaScript to implement the password generation and clipboard copy functionality.

## 🔄 jQuery

A fast, small, and feature-rich JavaScript library. The Password Generator uses jQuery to simplify DOM manipulation and event handling.

## 🔄 Bootstrap

A popular CSS framework for developing responsive and mobile-first websites. The Password Generator uses Bootstrap to create a responsive and mobile-friendly user interface.

## 🔄 Font Awesome

A comprehensive icon toolkit. The Password Generator uses Font Awesome to display icons in the navigation and controls.

## 🔄 Start Bootstrap

A collection of free and open-source Bootstrap themes and templates. The Password Generator uses Start Bootstrap assets to provide additional page styles and scripts.

## 🔄 GitHub Pages

A static site hosting service provided by GitHub. The Password Generator is deployed on GitHub Pages to make it accessible to users.
