# Password Generator Upgrade Guide

## 🔄 Upgrading from Version 1.0.0 to Version 1.1.0

### 🔧 Steps to Upgrade

1. **Backup your data**: Before upgrading, ensure that you have backed up any important data or configurations.
2. **Download the latest version**: Download the latest version of the Password Generator from the [GitHub repository](https://github.com/hmlendea/password-generator).
3. **Replace the files**: Replace the existing files in your project directory with the new files from the latest version.
4. **Test the upgrade**: Open the Password Generator in your web browser and test the new features and improvements.

### 🔧 New Features and Improvements

- **Added**: Support for additional character classes (extra symbols, brackets, others).
- **Added**: Enhanced user interface with improved layout and styling.
- **Improved**: Performance of password generation algorithm.
- **Improved**: Documentation for testing and contributing.
