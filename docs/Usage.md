# Password Generator Usage Guide

## 🔄 Generating a Password

1. **Open the Password Generator**: Open the Password Generator in your web browser by navigating to the deployed URL (e.g., [https://hmlendea.github.io/password-generator](https://hmlendea.github.io/password-generator)).
2. **Enter the desired password length**: Enter the desired length of the password in the length input field. The default length is 32.
3. **Select the character classes**: Select the character classes that you want to include in the password by checking the corresponding checkboxes. The available character classes are:
   - Digits (0-9)
   - Lowercase letters (a-z)
   - Uppercase letters (A-Z)
   - Symbols (?-*%!@#_$.:;/)
   - Extra symbols (€¢£¥₦§®©™∑∆µπ)
   - Brackets ([]{}()<>)
   - Others (,|\'"+=`~^& )
4. **Generate the password**: Click the Generate button to generate a password based on the selected character classes and length.
5. **View the generated password**: The generated password will be displayed in the password field.

## 🔄 Copying a Password to the Clipboard

1. **Generate a password**: Follow the steps above to generate a password.
2. **Copy the password**: Click the Copy button to copy the generated password to the system clipboard.
3. **Paste the password**: Paste the copied password into the desired location (e.g., password field, text editor, etc.).

## 🔄 Using the Password Generator on Different Devices

The Password Generator is designed to be responsive and should adapt to different screen sizes. However, for the best experience, it is recommended to use the Password Generator on a desktop or laptop computer.
